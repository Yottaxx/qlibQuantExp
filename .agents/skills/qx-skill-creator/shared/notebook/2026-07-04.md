**Expected.** If RankIC/IC are flat, the top/bottom decile portfolios should be ~unchanged ⇒ IR and MaxDD roughly flat too. A cross-sectional-ranking metric and a long-short book built from the same scores usually move together.

**Three explanations.**
1. n=1 noise. Row87 showed n=1 IR_wc swings of ~±1.0; +0.316 with a deeper DD is well inside that. The honest default — the IR gain is a seed artifact and evaporates on n≥3.
2. Real portfolio-shape effect: the demean coordinate `c_i=Wv·(u_i−mean u)` doesn't change the *ordering* (RankIC flat) but re-scales the *tails* — pushing more weight into extreme names ⇒ higher realized return AND deeper drawdown (a leverage/concentration effect orthogonal to rank quality). This would be a genuine, if double-edged, mechanism.
3. Cost-model interaction: contrast changes turnover (demeaning damps common-mode churn) ⇒ the WITH-cost IR gap (+0.316) is larger than a pure-return story predicts because friction drag dropped; the deeper MaxDD is then a separate concentration side-effect. Testable via the turnover metric.
