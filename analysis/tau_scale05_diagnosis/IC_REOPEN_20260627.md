## 1. The epistemic problem with the standing verdict

The standing decision (memo `MEMO_20260626.md`, ledger 84-85, memory `diagnosis_tau05_20260626.md`) is:
**"L-1 ceiling probe → GBDT/ridge max RankIC 0.0592 < model 0.0786 ⇒ DATA_SIGNAL_CEILING ⇒ stop chasing IC."**

This inference is **logically overstated**, and the adversarial workflow confirmed it (claim "the IC track is
reopenable" *survives* a steelmanned refutation, confidence 0.82):

1. **A classic-learner ceiling *below* the model is a *lower* bound on extractable signal, not an upper bound.**
   GBDT@0.0592 < model@0.0786 proves there is **≥0.0786** of signal in the data, not **≤0.0786**. The model
   *beating* the GBDT is direct evidence of structured signal tabular learners miss — consistent with *more*
   being capturable, not less.
2. **The probe only ever bounded *one representation*.** `ceiling_probe_raw_alpha158.py` fed ridge/LGBM the
   **same per-stock `RobustZScoreNorm` features** the model uses (verified: pooled per-feature median/MAD fit on
   2008-01..2020-03, clipped ±3 — qlib `processor.py:262-297`). It **never tested a cross-sectional input
   representation.** So 0.0592 says nothing about a feature set that includes today's relative coordinate.

The original "3-zone" pre-registration required references to land *near* 0.0786 to call a ceiling; they landed
0.0194 *below* it — an outcome the rule didn't cleanly cover, and which was read as "capped" when it actually
means "the model already out-extracts a GBDT on per-stock features." **In Popper/Lakatos terms: the data-cap
hypothesis was asserted, not falsification-tested against the CS representation. The decisive test was skipped.**

**Honest caveat (the skeptic's strongest point, and it stands):** the *realized* headroom is probably small.
Selection-corrected model RankIC is ~0.073 (valid==test, epoch+seed inflation ~+0.006), only ~0.014 above the
GBDT. L-4's pre-registered kill line (+0.005) sits *at* the n=6 minimum-detectable-effect floor on a contaminated
split. So: **the IC track is reopenable in principle, but any gain may be too small to confirm honestly.** That is
exactly why the next move is a **cheap decisive diagnostic, not a GPU-day training run.**

## 2. The structural IC bottleneck (code-verified)

The task metric (IC/RankIC) is **cross-sectional** — rank stocks against each other *on a given day*. The system
is misaligned with it on three axes simultaneously:

| Layer | State | Evidence |
|---|---|---|
| **Target** | per-day **cross-sectional** (`CSZScoreNorm` robust) | `work_flow.py:107` |
| **Input** | per-stock **absolute**, global-fit, clipped ±3, NaN→0 | `work_flow.py:93-99`; qlib `processor.py:262-297` |
| **Backbone** | **cross-sectionally blind** (stock axis `B` is a pure batch dim in both experts; router per-day; perturbation leak ~1e-5) | `moe_block.py:234,243`; ledger 84 |

The **relative coordinate that *defines* a cross-section** — "where does this stock rank among today's peers on
each factor" — is **literally absent from the input**, and the architecture **cannot compute it** (CS-blind). The
model is asked to predict a cross-sectional z-score from inputs that carry no day-relative position. This is the
cleanest mechanistic reason IC is hard here, and it is **untouched by the data-cap argument** (which bounded only
the per-stock representation).

### Input value-range corollary — a covariate-shift the project never attacked from the input side
Feature stats are **frozen on the pre-COVID window (2008-01..2020-03)** and applied unchanged to the post-COVID
test (2020-07..2022-12). Under the COVID volatility regime, post-COVID normalized features are systematically
**off-center / mis-scaled, with more values saturating at the ±3 clip** — a real train↔test *input* mismatch
(verified; the processor caches 316 stale scalars driving every test-day transform). This is a concrete
**input-side** contributor to the "gen-gap wall," and every gen-gap lever tried so far (sampler, EMA, capacity)
lives *downstream* of the input and could not touch it. A **per-day CS coordinate is shift-invariant by
construction** (caches zero stats).

## 3. The one untried, theory-aligned, MSE-compatible IC lever

**L-4 — append per-day cross-sectional rank/z of features as NEW input channels** (keep the global-normalized
features; *add* the CS coordinate). Verified **never run** (`cs_input_channels_ever_run=false`; L-4 was gated
behind the L-1 probe, which fired "capped" and closed the track before Step 1). Survives adversarial refutation as
**genuinely novel and non-fatal** (confidence 0.60 — survives on novelty, *not* as a promise of lift).

Why the **append** form specifically (and **not** wholesale CS-normalization):
- **Honors the standing regime-info rule** (`project_rst_moe.md:52`: "never CS-normalize features — destroys the
  regime info `RegimeContextEncoder`/`layer_summary` consume"). Appending keeps the global common-mode features
  (regime intact) **and** adds the shift-invariant relative coordinate. Best of both worlds; the conflict is only
  with *replacing* normalization, which we do not do.
- **Zero inter-stock message passing** → distinct from the killed `CrossStockBlock`/3-expert (representational
  cross-stock operators, ledger 81) and the killed factor-pool reweight (ledger 67-71).
- **Keeps MSE** — it is an *input* change, not a loss change.

**Mandatory guards** (from the refutation): compute CS-rank **point-in-time on day-T peers of the pre-clip raw
feature** over the true PIT universe (no lookahead / survivorship); add a **hard train==infer feature-schema
assert** to defeat the silent trailing-channel truncation in `_coerce_feature_dim` (`model_adapter.py:779-853`,
which would otherwise make the lever a silent no-op); `/quant-leakage-audit` first.

## 5. Monitoring gaps that would make any IC gain visible (free, post-hoc on `pred.pkl`)

The pipeline logs a rich IC/RankIC/ICIR + diagnostic suite, but for an IC/RankIC-targeted loop it is **missing**:
1. **Decile monotonicity / full long-short curve** (only a single top30−bot30 label spread exists).
2. **precision@30 / NDCG@30 aligned to the `topk=30, n_drop=5` trading rule** — money is made on 30 names, but
   every IC metric is full-universe.
3. **IC decay across horizons** (h=1,2,3,5,10; the docstring claims it, no code computes it).
4. **Per-regime conditional ICIR + significance** (current regime buckets report only conditional *mean*, depend
   on the precomputed `market_state` pkl, and silently produce nothing without it).
5. **MSE-implied-IC / dispersion anchor** — `score_std`/`label_std` are logged but never tied to the MSE optimum
   `std(p)*≈IC·std(y)`; no shrinkage diagnostic. Given the live loss is plain MSE, this is the missing anchor for
   telling "low IC = under-dispersion artifact" from "low IC = signal ceiling."

All five are pure post-hoc computations on saved predictions — no GPU, and prerequisite for *attributing* any
future IC change.

## 6. EMPIRICAL RESULT (2026-06-27, both probes ran — leakage-clean, full 611-day test)

`scripts/ceiling_probe_cs_rank.py` (snapshot) + `scripts/ceiling_probe_cs_rank_window.py` (model-matched window).
Both reproduce the L-1 baselines exactly (R-snapshot 0.0535, raw-window 0.0592), so the pipeline is byte-faithful.

| representation | base | +CS-rank | **lift** |
|---|---|---|---|
| **snapshot** (day-T, 158) | 0.0535 | 0.0620 | **+0.0085** |
| **window** (8×158, model-matched) | 0.0592 | 0.0625 | **+0.0033** |

A parallel independent probe (`scripts/ceiling_probe_csrank.py`) found the snapshot lift +0.0095 — cross-validates.

**Reading (the decisive nuance the snapshot alone hid):**
1. **The reframe is VINDICATED — CS-rank carries real extractable cross-sectional signal the per-stock features
   lack.** The "data-capped → stop IC" verdict WAS logically overstated; the "CS-rank is a rank-invariant no-op"
   refutation is empirically dead (+0.0085 snapshot, ~10σ on seed noise).
2. **BUT the model-matched headroom is MARGINAL, not large.** CS-rank is ~60% redundant with the 8-step temporal
   window (lift collapses +0.0085 → +0.0033 once the baseline already has the window). The orthogonal,
   model-relevant GBDT-extractable headroom is **~+0.0033 — BELOW L-4's +0.005 n=6 kill line.** Both the GBDT-RW
   and the model are per-row/CS-blind on the windowed per-stock features, so the windowed GBDT is a fair proxy:
   CS-rank is a genuinely cross-sectional coordinate neither can compute internally, hence the residual lift is
   real and (being orthogonal) ~architecture-independent — but small.
3. **The model still sits above all of this** (0.0786, honest ~0.073 vs windowed-GBDT 0.0625). If CS-rank's
   orthogonal +0.0033 transfers additively, the model lands ~0.076–0.082; the model *might* exploit the channel
   better than tree splits (tokenizer/attention/regime interactions) or get the CS-rank *time-series* (this probe
   under-powered it with day-T only), nudging it up — or it might capture less (diminishing returns on a richer
   base). Unknown without a run.

**Refined recommendation — L-4 is a marginal-but-real lever; resolve it CHEAPLY before an n=6 commit:**
- File the L-4 `/quant-hypothesis` card (kill line +0.005) + `/quant-leakage-audit` on the point-in-time CS-rank
  processor (both zero-GPU).
- Then a **single-seed `/quant-minimal-repro`** (~1.5–3 GPU-hr, NOT the full ~0.6 GPU-day n=6): does the model move
  ≥ ~+0.003 toward/over +0.005? Escalate to n=6 only on a pass; kill cheaply on a flat.
- **GPU-allocation note:** L-6 (portfolio-IR, already running in parallel) attacks a *structurally guaranteed* gap
  (MSE portfolio-blindness), whereas L-4's IC headroom is now measured-marginal. If GPU is contended, L-6 keeps
  priority; L-4 is the IC-track complement, worth the *cheap* staged probe but not a blind n=6 bet.

**Philosophical coda (why the staged probe mattered):** the snapshot (+0.0085) looked like a clean reopening; the
model-matched window (+0.0033) showed most of it was information the model already has. Neither probe was wrong —
they answered different questions, and only the model-matched one is decision-relevant. The CPU-minutes spent here
saved a likely-disappointing 0.6 GPU-day and corrected a binary "capped/not-capped" frame into the true
*quantitative* one: **reopenable, but the door is only open a crack.**

## 8. SESSION SYNTHESIS — the IC is near its extractable ceiling; cheap MSE levers plateau ~0.081

Three independent cheap probes converge:

0.0592 data ceiling, which the model has largely exhausted), or (b) accept IC is near-ceiling and shift to the
**portfolio-IR track (L-6)** where MSE's *structural* blindness leaves a guaranteed (non-marginal) gap on

**Actionable, honest ranking for the IC goal (MSE kept):**
